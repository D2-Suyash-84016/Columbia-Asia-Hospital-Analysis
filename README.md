# 🏥 Columbia Asia Hospital Data Analysis (Power BI)

## 📌 Project Overview
This project focuses on analyzing hospital operational and billing data to generate actionable insights for improving patient experience and strategic decision-making. The analysis highlights department performance, patient demographics, satisfaction levels, and revenue trends using Power BI.

## 📊 Data Description
The project uses two primary datasets:
- **Transactional Data:** Patient demographics, doctor assignments, appointment details, and fees  
- **Billing Data:** Department-wise billing, doctor details, patient IDs, and total bill amounts  

Each dataset contains over **6,000+ records** and was cleaned and transformed before analysis.

## 🛠 Tools & Technologies
- Microsoft Power BI Desktop  
- Power Query Editor  
- DAX (Data Analysis Expressions)

## 🔍 Methodology
- Data cleaning and preprocessing (duplicates, missing values, formatting)
- Data modeling by joining transactional and billing datasets
- Creation of DAX measures for KPIs such as total revenue, average satisfaction, and visit counts
- Interactive dashboard creation for clear visualization and insights

## 📈 Key Insights
- **General Practice** and **Orthopedics** are the most visited departments
- Patient gender distribution is nearly balanced
- **Gastroenterology** records the highest patient satisfaction score
- Staffing optimization can significantly reduce wait times and improve service quality
- Discount strategies based on patient satisfaction can enhance retention

## 💡 Recommendations
- Increase staffing in high-traffic departments
- Optimize doctor shift allocation to manage patient flow efficiently
- Introduce satisfaction-based discount strategies
- Re-evaluate financial strategies to improve profitability

## 🎯 Conclusion
This project demonstrates how healthcare data analytics can improve operational efficiency, patient satisfaction, and revenue planning. It showcases strong skills in data cleaning, modeling, DAX, and dashboard design using Power BI.
